Install Agenteeq. No Terminal needed.

Download the app for your computer, move it into place and allow it once. You don’t need an account or anything else.

Mac

Four steps, once.

You allow it once in System Settings; from then on it opens with a double-click.

  1. 1Download and unzip

    Click Download for Mac. A ZIP file appears in your Downloads – double-click it to unzip Agenteeq.

  2. 2Drag it to Applications

    In Finder, drag Agenteeq into the Applications folder. That’s the installation.

  3. 1Download and open

    Click Download for Mac and double-click Agenteeq in your Downloads. A window opens with the app and the Applications folder.

  4. 2Drag it to Applications

    In that window, drag Agenteeq onto the Applications folder. That’s the installation; then close the window.

  5. 3Open it

    Open Agenteeq from the Applications folder. macOS says it can’t verify the app. Close the dialog – don’t move the app to the Trash.

  6. 4Allow it in Settings

    Open System Settings → Privacy & Security, scroll down to Security and click Open Anyway. Enter your Mac password and confirm with Open.

The Open Anyway button stays in Settings for about an hour after you try to open the app. Per Apple’s help.

For advanced users: install with one command

If you live in Terminal, one command can replace steps 1–4. It downloads the latest release, verifies it, installs it in Applications and opens it.

$ curl -fsSL https://agentree-fawn.vercel.app/install.sh | bash

The script checks the package’s SHA-256 digest against GitHub and installs nothing if they differ. It moves the old version to the Trash. Read the script

Windows 10 and 11 · beta

A trial version for Windows.

Three steps, once.

Download for Windows
  1. 1Extract the ZIP

    Right-click the downloaded Agenteeq-…-Windows-x64.zip file and choose Extract All. You get an Agenteeq folder.

  2. 2Run Agenteeq.exe

    Leave the folder where it is or move it. Inside, double-click Agenteeq.exe.

  3. 3Confirm SmartScreen

    The build isn’t signed yet, so Windows shows a SmartScreen warning. Click More info, then Run anyway.

What Windows doesn’t have yet. The app can’t yet store keys in the system password store, open a conversation directly in its app, continue in a terminal or start at sign-in.

The window needs the WebView2 runtime, which Windows 11 includes and Edge brings to Windows 10. The SmartScreen warning is described in Microsoft’s documentation.

Add to Chrome

The extension pairs with the app on its own while Agenteeq is running.

  1. In the app, open Settings → Connections → Chrome extension and click Copy path.
  2. In Chrome, open chrome://extensions and turn on Developer mode in the top right.
  3. Click Load unpacked and choose the copied folder (on a Mac, press ⇧⌘G in the dialog and paste the path).
  4. That’s it. The extension pairs with the app on its own.

If something doesn’t work.

I don’t see Open Anyway in Settings

The button appears only after you try to open the app and stays for about an hour. Open Agenteeq from the Applications folder again, close the dialog and go back to System Settings → Privacy & Security.

macOS says the app is damaged

Move the downloaded copy to the Trash, download it again and repeat the steps. If the message stays and Open Anyway doesn’t appear in Settings, use the one-command install above – a file downloaded in Terminal doesn’t get quarantined – or let us know on GitHub.

How do I update Agenteeq?

The app checks for new releases itself and offers them in the top bar and in Settings → Updates. It opens the downloaded package in Finder; quit Agenteeq (⌘Q) and replace it in Applications. Your data and settings stay.

How do I uninstall it?

In Agenteeq, first turn off the Claude Code connection (Settings → Connections), then quit the app and move it to the Trash. Delete your data with the ~/.agenteeq folder in your home folder.

Can I send Agenteeq to a colleague?

Yes. Send them a link to this page – everyone installs their own copy and connects their own agents. Nothing is shared with your account or computer.
