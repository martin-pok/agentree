Privacy policy

Agenteeq is an app on your computer. The text of your AI conversations, their titles, folder paths and code never leave your computer. The account is optional and everything works without it.

Who processes the data

The Agenteeq app, the Chrome extension and this website are run by their author. Send privacy questions and GDPR requests through the project page on GitHub.

The desktop app

  • What it reads: files that AI tools store on your computer themselves (for example Claude Code, Codex or Cursor transcripts). It reads them only on this computer and keeps its overview in the app’s own folder.
  • What it sends to the internet: on its own, only a request for the Czech National Bank’s daily exchange rates for currency conversion. It contains none of your data.
  • Only if you turn it on: API spend through the official Anthropic or OpenAI interfaces with your admin key (the key stays in the macOS Keychain and goes only to that provider), and the Agenteeq account described below.
  • Connecting models: signing in to Claude Code or Codex happens directly with their provider. Agenteeq never sees your passwords or access keys. From the tool it learns only whether it is signed in and the plan name.
  • The app has no telemetry or analytics and shares nothing with third parties.

Chrome extension

The extension adds conversations from web AI services to the app. It runs only on these addresses: chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, copilot.microsoft.com, perplexity.ai, grok.com, chat.qwen.ai and github.com/copilot.

  • What it reads from the page: which service it is, the ID and address of the open conversation, whether the service is currently responding, how many messages are from you and from the AI, the model name, and the text of a limit notice if the service shows one.
  • What it never sends: the text of your messages or replies, the conversation title, attachments, cookies or your browsing history.
  • Where it goes: only to the Agenteeq app on the same computer (address 127.0.0.1). The extension sends nothing to any server on the internet.
  • What it stores in the browser: the access key from pairing with the app, the list of services you turned off, and the last connection status.
  • Inserting a prompt: when you start an agent in a web service from the app, the extension pastes your prompt into that service’s window. The prompt comes from the app on your computer.
  • Page check: at your request, the extension can save a description of the page structure to a file on your computer, used to fix site adapters. It contains no text from the page and is never sent anywhere automatically.

Data from the extension is used only for the function described above. It is not sold, not transferred to third parties, and not used for advertising or to determine creditworthiness. The extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Optional Agenteeq account

  • Sign-in: with Google. Google gives us your email and the basic profile details it shares at sign-in.
  • Summary sync (only if you turn it on): device name and system, app version and when it was last seen, token and conversation counts per day and provider, spend per month and service, limit usage and reset times, agent counts by status, and which models you have connected (plan and status). Conversation text, titles, folder paths, expense notes and code are never sent.
  • Where: a Supabase database in the Frankfurt region (EU). Everyone sees only their own rows.
  • Deletion: in the app under Settings → Account → Delete account. It deletes the account and everything stored with it in the cloud. Data on your computer stays.

This website

The website is hosted on Vercel, which, like any server, processes technical request data such as the IP address in standard operational logs. The website uses no analytics and no advertising or tracking cookies.

Your rights

You have the right to access, correct and erase your data, to restrict processing, to data portability and to object. You can file a complaint with the Czech Office for Personal Data Protection (uoou.gov.cz) or your local authority. Most of the data lives on your own computer, and you can delete it yourself at any time.

Changes

When this policy changes, you’ll see it here with a new effective date. Significant changes are also described in the app’s release notes.
