Install

Download one file, move the app into place and allow it the first time. No Terminal, no account.

Mac

Download for Mac

Apple Silicon (M1 or later)macOS 14 or later

  1. 1Open the downloaded file

    Agenteeq is in Downloads. Double-click it to open a window with the app.

  2. 2Drag Agenteeq to Applications

    In the window, drag the Agenteeq icon onto the Applications folder. That’s the install.

  3. 3Open it and click Done

    Open Agenteeq from Applications. The first time, macOS says it can’t verify the app – click Done.

  4. 4Allow it in System Settings

    Open System Settings → Privacy & Security, scroll down to Agenteeq and click Open Anyway. Confirm with your password and click Open once more. Next time it opens with a double-click.

Working in Terminal? The one-command install skips step 4.

Windows (beta)

Download for Windows

Windows 10 and 11 (64-bit)beta

  1. 1Extract the downloaded file

    Right-click it and choose Extract All.

  2. 2Run Agenteeq.exe

    It’s in the extracted Agenteeq folder. Keep the folder together – the app needs the files next to it.

  3. 3Allow it the first time

    If Windows shows the blue SmartScreen window, click More info and then Run anyway.
