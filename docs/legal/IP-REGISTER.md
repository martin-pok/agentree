### Public-repo licensing policy
Repo `martin-pok/agentree` is currently PUBLIC with GitHub API `license=null`. Absence of a declared licence generally means no general permission to copy, modify or distribute copyrighted original code beyond applicable law and platform terms; **it does not establish that every contributed file is exclusively owned by the repository administrator**. Do **not** add MIT/Apache/GPL or blanket © ownership without an affirmative product strategy and rights-chain check. If choosing proprietary source, add an appropriate verified rights notice and third-party NOTICE only after legal review; choose separate open-source subsets deliberately. A public readme is not a trade mark filing.

- [ ] Search identical and confusingly similar `Agenteeq`, `Agentree` and phonetic/visual variants in **ÚPV registry**, **EUIPO TMview/EUTM**, and important target markets before claiming exclusivity. Log dated screenshots/search terms **in a private vault**, not publicly disclose full legal strategy.
- [ ] Check application name, domain, Store developer identity, relevant GitHub/other social handles and risk of existing similar brands; domain registration alone is not trade mark protection.
- [ ] Map actual goods/services; likely Nice **class 9** for downloadable software and **class 42** for SaaS/software; confirm exact wording and jurisdictions with IP counsel. Add other classes **only if genuinely used/planned**.
- [ ] Determine who files, contract chain to original authors, clearance outcome, opposition risk, enforceability, calendar for renewal and correct symbol. Use **no ®** until there is a registered mark for the jurisdiction.

Additional professional fees or class fees possible. Official sources: https://upv.gov.cz/prumyslova-prava/ochranne-znamky/narodni-prihlaska-ochranne-znamky and https://www.euipo.europa.eu/en/online-services .
